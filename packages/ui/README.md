# @sentrix/ui

Shared React components and design system for the Sentrix platform.

## Contents

- `Button` — Button component with primary/secondary variants
- `Card` — Card surface component

## Usage

```tsx
import { Button, Card } from "@sentrix/ui";

export function Example() {
  return (
    <Card title="Threat Alert">
      <Button variant="primary">Investigate</Button>
    </Card>
  );
}
```
